The Esgode mark: three rings — two stacked and joined by a short bar, one set to the upper right. Supplied by the store as a white-on-black PNG; the two transparent files are cut from it pixel for pixel, never redrawn.

- `esgode-mark-ink.png` — ink `#1d1d1f` on transparent. Use on `surface` and `surface-raised` in the light theme.
- `esgode-mark-white.png` — white on transparent. Use on `surface` and `surface-raised` in the dark theme, and on `accent` or `ink` fills in either theme.
- `esgode-signage-reference.jpg` — crop of the storefront sign: the lockup (wordmark with the mark as the g, "tech store" beneath). Reference for the lockup proportions and the lettering; not for the UI.
- `esgode-mark-original.png` — the file as received, white on black. Reference only; do not place it in the UI.

Sizes: 24px in the sidebar beside the wordmark, 40px in the login header, 64px on empty states and the splash. Keep a clear space of half the mark's width on every side. Never recolour, outline, rotate or add a shadow.

The source is 114 × 110 px: it is sharp up to 64px on a 2× screen and no further. Ask the store for an SVG or a 1024px PNG before using it larger.
